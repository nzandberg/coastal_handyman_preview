# Project Summary: Coastal Handyman Landing Page

## 1. Core Brand Strategy
* **Business Name:** Coastal Handyman (Officially registered as *Coastal Handyman Solutions Ltd*).
* **Catchline / Hook:** "The Shore Fix."
* **Target Audience:** Coastal residential properties requiring maintenance, minor repairs, and small building projects.
* **Key Competitive Advantage:** Headed by Richard Clark, a **Qualified NZ Builder** (elevates credibility above standard handymen).

## 2. Infrastructure & Technical Stack
* **Hosting Platform:** GitHub Pages (Static hosting).
* **Domain Strategy (NZ):** * Primary target domain: `theshorefix.co.nz` (or `coastalhandyman.co.nz`).
    * *Recommendation:* Purchase both if budget allows; use one as primary and redirect the secondary domain to it.
* **Frontend Framework:** Single-page application built with clean HTML5 and **Tailwind CSS** (loaded via CDN for zero-configuration, lightning-fast static delivery).
* **Backend / Form Handling:** **Formspree.io** integration embedded into the contact form to handle dynamic email routing without a custom backend server.

## 3. Business Pricing Model (Tiered Structure)
To optimize profitability and manage travel overheads, the business uses a two-tier pricing strategy to transparently manage expectations:
* **Small Maintenance Jobs (< 2 Hours):** Flat local **Call-Out Fee + Hourly Rate** from minute one to cover vehicle wear, fuel, and travel time.
* **Larger Building Projects (Decks, Retaining Walls, etc.):** **Free Quoted Estimate**. The cost of the initial site scoping visit is completely absorbed into the overall fixed project quote.

## 4. Competitive Benchmarks (Christchurch Market)
Inspiration for the landing page layout and copy structures were drawn from successful local operators:
* `1handyman.co.nz`: Excellent minimalist, hyper-focused "1-man band" layout focusing on high-value micro-scenarios.
* `christchurchhandyman.co.nz`: Strong personal branding using an approachable "Our Story" layout that builds immediate community trust.
* `handymanchristchurch.co.nz`: Great framing around solving the client's problem of finding tradespeople who *actually want* to take on smaller, lingering task lists.

    * An "About Richard" bio section.
    * A 3-column service grid (Small Fixes, Big Builds, Coastal Care).
